📖 Theory & Viva Examination Guide

1. What is a Non-deterministic Finite Automaton (NFA)?

An NFA is a 5-tuple M = (Q, Σ, δ, q₀, F) where the transition function δ maps (state, symbol or ε) to a set of states: δ: Q × (Σ ∪ {ε}) → P(Q). The automaton can transition along multiple paths in parallel.

2. What is a Deterministic Finite Automaton (DFA)?

A DFA is a 5-tuple M = (Q, Σ, δ, q₀, F) where the transition function is total and deterministic: δ: Q × Σ → Q. For every state and symbol, there is exactly one unique target state. Epsilon transitions are not permitted.

3. What is an Epsilon (ε) Transition?

An ε-transition allows the automaton to spontaneously change state without consuming any input symbol from the string. It enables modular design and sub-automaton chaining.

4. What is Epsilon Closure (ε-closure)?

For any set of states S, ε-closure(S) is the set containing S plus all states reachable from S by traversing zero or more ε-transitions. Cycles are handled safely using a visited set.

5. How does Subset Construction work?

Subset construction converts an NFA to a DFA where each DFA state corresponds to a subset of NFA states. Start state D₀ = ε-closure({q₀}). For each subset S and symbol a, compute target T = ε-closure(move(S, a)). If T is new, add it to the queue.

6. What makes a DFA state accepting?

A DFA state S is an accepting state if and only if S contains at least one accepting state of the original NFA: S ∩ F_NFA ≠ ∅.

7. What is a Dead / Trap State (∅)?

When an NFA move has no valid destinations, it yields the empty set ∅. In a complete DFA, ∅ is materialized as an explicit non-accepting Dead/Trap state with self-loops on every alphabet symbol.

8. Why can an NFA have multiple active states?

Non-determinism conceptually explores multiple branches simultaneously. The active state set at any point represents all states reachable by all valid paths after consuming the input prefix.

9. Why does a DFA have exactly one next state?

Determinism means unambiguous execution: given current state q and input symbol a, δ(q, a) yields a single deterministic target state, making it directly implementable in hardware or software.

10. Why does the converted DFA recognize the exact same language?

Language Equivalence Theorem: By mathematical induction on string length |w|, δ_DFA(D₀, w) tracks exactly the active subset of states reachable by the NFA on w. Since a DFA state is accepting iff it contains an NFA accepting state, w is accepted by DFA iff w is accepted by NFA.
